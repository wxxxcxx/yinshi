# PRD v0.3

## 1. 目标与范围
- 目标：PWA 输入身高/体重/年龄/性别/训练情况，计算热量与宏量，并展示训练日/休息日餐序与计算步骤。
- 范围：
  - 减脂/增肌
  - 8 种训练场景（含无力训）
  - 计算公式严格按文档
  - 知识库首版包含完整 Excel 内容索引
- 所有复杂计算相关数据外置为 JSON 文件加载

## 2. 输入
- 身高（cm）、体重（kg）、年龄
- 性别（男/女）
- 目标（减脂/增肌）
- 训练水平（新手/有基础/老手）
- 训练时间场景（8 选 1）
- 有氧项目与每周小时数（可多选）

## 3. 输出
- 计算步骤（BMR → b → c/d → e1/e2 → f1/f2）
- 力训日/休息日热量与宏量总量
- 餐序时间线
- 每餐碳水/蛋白拆分
- 脂肪配额

## 4. 计算规则（严格）
- BMR、b、c、d、e1/e2、f1/f2 与脂肪配额保持不变（见 v0.2）
- 有氧消耗、体重四舍五入、线性外推：来自数据文件

## 6. 餐配额拆分规则（新）
来源：`/Users/W/Workspace/Personal/撸铁/data/meal_quota_splits.json`

### 训练日（按占位符格式提取）
- 早饭=练前：碳水 15%，蛋白 20%
- 练后餐：碳水 35%，蛋白 20%
- 其他餐：碳水 20%，蛋白 20%
- 晚饭=其他：碳水 20%，蛋白 20%
- 零食/夜宵：碳水 10%，蛋白 20%

### 休息日
- 早饭：沿用“绿表早饭”（碳水 15%，蛋白 20%）
- 零食/夜宵：沿用“绿表零食夜宵”（碳水 10%，蛋白 20%）
- 午饭碳水：40%（你指定）
- 晚饭碳水：35%（你指定）
- 蛋白质午/晚：各 30%（来自占位符格式）

### 特殊
- “蛋白质不用吃” → `protein_pct = 0`
